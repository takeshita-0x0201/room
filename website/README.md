# Room Landing Page

The official landing page for [Room](https://github.com/takeshita-0x0201/room), a lightweight open-source macOS menu bar app for memory pressure, storage, and safety-first cleanup.

## Development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
npm test
```

The site is built with React, TypeScript, Tailwind CSS, and vinext for deployment to Cloudflare Workers.
